# Rede Florescer

Projeto desenvolvido como atividade prática do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

A Rede Florescer é um site desenvolvido com o objetivo de apresentar uma iniciativa social voltada à solidariedade, inclusão, educação e apoio comunitário.

## Estrutura do projeto

O projeto é composto pelas seguintes páginas:

* `index.html` — página inicial.
* `projetos.html` — apresentação dos projetos sociais.
* `cadastro.html` — formulário para demonstrar interesse em participar.
* `imagem rede florescer.jpeg` — imagem utilizada no site.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git e GitHub
* GitHub Pages

## Acessibilidade

O projeto utiliza elementos semânticos do HTML e recursos ARIA para melhorar a estrutura e a acessibilidade da navegação.

## Publicação

O projeto foi versionado no GitHub e publicado utilizando o GitHub Pages.
